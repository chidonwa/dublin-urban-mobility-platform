# dublin-urban-mobility-platform
End-to-end data engineering and analytics platform integrating Dublin mobility and weather data using Python, PostgreSQL, dbt, Airflow, Docker and Power BI.
## Project Objectives
This project will:
- Ingest real Dublin mobility and weather data from multiple sources.
- Clean, validate and store the data in PostgreSQL.
- Transform raw datasets into analytics-ready models using dbt.
- Orchestrate scheduled data pipelines with Apache Airflow.
- Containerise the project environment using Docker.
- Analyse mobility patterns using Power BI.
- Identify station utilisation trends, peak travel periods and weather-related demand shifts.
## Planned Technology Stack

- PostgreSQL

- Apache Airflow
- Docker
